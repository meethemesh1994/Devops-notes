opentelemetry
=============
industry standard common interface for observability, it is vendor neutral. it created a common protocol to collect, process and export the metrics to different backends we can choose

in a full request, app teams create a trace id, everything is span inside trace. for example frontend is one span, backend is one span

exemplers
=========
are trace refereences attached to specific request in histogram since histogram cant store each and every request. exemplers tags with trace id when the latency graph started, we can click exemplers to go to traces...
